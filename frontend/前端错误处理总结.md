# 前端错误处理总结

## 分层处理模型
1. API/工具层：标准化错误对象（业务错误/系统错误）
2. 页面组合函数层：`useAsyncError` 统一异步错误捕获
3. 组件层：`GlobalErrorBoundary.vue` 兜底渲染异常
4. 全局层：`main.js` 注册 `error` / `unhandledrejection` 监听

## 实践约定
- 业务错误：提示用户可理解信息，不打断页面主流程。
- 系统错误：记录详细上下文，必要时进入错误边界 UI。
- 登录接口 401：按业务错误处理，不应直接强制跳转导致体验异常。

## 排查建议
- 先看浏览器 Console 与 Network 请求状态。
- 再检查 `utils/http.js` 的拦截器分支。
- 最后检查页面是否正确使用 `useAsyncError`。
