📂 music_project/
├── 🎨 前端展示层
│   ├── 首页 - 歌曲列表
│   ├── 歌曲列表 - 搜索
│   ├── 播放器 - 音乐播放功能
│   └── 详情页 - 歌曲信息展示/评论区
│
├── 🛠️ 后端业务层
│   ├── 用户管理 - 登录/注册
│   ├── 歌曲管理 - 上传/删除/编辑/用户上传的歌曲是公开的/歌曲按照用户分类
│   └── 播放历史 - 记录用户行为
│
└── 💾 数据存储层
    ├── 歌曲数据库
    ├── 用户数据库
    └── 媒体文件存储


层级	推荐方案
前端	HTML5 + CSS3 + JavaScript / Vue.js / React
播放器	HTML5 Audio API 或 Aplayer.js
后端	Node.js + Express / Python + Flask
数据库	MySQL / MongoDB
存储	本地存储 / 阿里OSS / 七牛云

首页 (index.html)
├── 导航栏
├── 轮播图/Banner
├── 歌曲列表
└── 底部信息

歌曲列表 (songs.html)
├── 搜索/筛选
├── 歌曲表格
└── 分页

播放页面 (player.html)
├── 播放器控制
├── 歌曲信息
├── 歌词展示
└── 评论区

🎵 songs 表
├── id
├── title (歌曲名)
├── artist (艺术家)
├── album (专辑)
├── duration (时长)
├── cover (封面)
├── audio_url (音频链接)
└── created_at

👤 users 表
├── id
├── username
├── email
├── password
└── favorites (收藏列表)


📋 技术栈选型：

前端：Vue.js 3 + Vite + Axios
后端：Node.js + Express
数据库：MySQL (易于管理) 或 MongoDB (灵活性好)
认证：JWT Token
